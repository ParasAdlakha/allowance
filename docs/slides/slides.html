A payment tool does whatever the agent asks. PayPal's Agent Toolkit, Agent Ready and AP2 mandates make agent checkout possible. What's missing is the enforcement point between "the agent wants to pay" and "money moves".

Eval · same errands, same model, same shops

Even a model that ignores injections broke the mandate in 1 of 4 errands.

Allowance gate
$0.00

12 errands, gemini-3.5-flash-lite, dollars paid outside the signed mandate. It resisted every planted instruction, but paid a checkout price 33% above the page, broke a $60 per-order cap, and skipped an approval the owner asked for. A hardened prompt changed nothing. Behind the gate: $0, and task success rose from 75% to 100%.
